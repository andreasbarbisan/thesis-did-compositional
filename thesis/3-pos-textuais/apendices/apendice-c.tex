\chapter{Diagnóstico de Regressão à Média} \label{ap:regmedia}

Este apêndice compara a especificação principal com a restrição de suporte de linha de base. O objetivo é verificar se os resultados principais dependem de comparar escolas tratadas inicialmente fracas com controles muito distantes na distribuição pré-tratamento.
